# Fable 5.0.0 — Mining

Juego de minería incremental para navegador, compatible con móvil y escritorio.

## Cómo jugar
1. Abre `index.html` en un navegador o en la vista previa de Acode.
2. Toca la roca para extraer minerales.
3. Vende minerales para conseguir monedas.
4. Compra mejoras de pico y mineros automáticos.

## Archivos
- `index.html`: interfaz y estructura.
- `style.css`: diseño adaptable.
- `game.js`: mecánicas, mejoras y guardado local.

El progreso se guarda automáticamente en `localStorage` del navegador.
